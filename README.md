# WORLD BEYOND: 3D Solar System & Planetary Exploration Simulator

**WORLD BEYOND** is a high-fidelity, interactive web-based 3D solar system simulator and human survival laboratory built with React, TypeScript, Three.js, Tailwind CSS, and Vite. 

---

## ✨ Key Features

* **Interactive 3D Solar System**: Real-time orbital mechanics, customizable orbit speeds, pause/resume controls, and click-to-zoom planetary navigation powered by Three.js.
* **Mars Landing & EVA Simulation**: An immersive surface landing sequence featuring interactive vehicle switching (Astronaut EVA vs. Rover), real-time telemetry (Oxygen, Temperature, Radiation), and point-of-interest (POI) scientific discoveries.
* **Exoplanetary Survival Lab**: A dynamic gear configuration and life support evaluation engine that calculates mission readiness scores and hazard warnings based on thermal, barometric, and radiation constraints.
* **Comparative Planetary Science**: A multi-world metric comparison matrix contrasting surface temperatures, gravity, atmospheric composition, and day lengths.
* **Web Audio Sound Synthesizer**: Procedural sci-fi sound effects built using the native Web Audio API for interactive feedback.
* **Supabase Cloud Integration**: Architecture support for user session tracking and exploration metrics.

---

## 🚀 Tech Stack

* **Frontend Framework**: React 18, TypeScript, Vite
* **3D Graphics & Rendering**: Three.js
* **Styling & UI**: Tailwind CSS, Lucide React Icons
* **Deployment**: Vercel
